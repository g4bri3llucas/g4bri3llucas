## Projetos

### [Atlas](https://github.com/g4bri3llucas/atlas-countries)
Explorador de países com lista de viagem ("já visitei" e "quero visitar"). 250 páginas geradas estaticamente (SSG), busca e filtro com SSR, estado global com Redux Toolkit e comparador de países com Zustand.
**Next.js · TypeScript · Redux Toolkit · Zustand** (em desenvolvimento)

### [PixelStore](https://github.com/g4bri3llucas/PixelStore)
E-commerce de jogos digitais (MVP), com integração à API RAWG, autenticação JWT e PWA.
**React · TypeScript · JWT**

### [Pulseboard](https://github.com/g4bri3llucas/pulseboard)
Painel de monitoramento de disponibilidade (uptime) e gestão de incidentes para equipes pequenas.
**TypeScript · Node.js · React · PostgreSQL**

### [Movie Search App](https://github.com/g4bri3llucas/Movie-Search-App)
Busca e detalhes de filmes com a API TMDB, navegação com React Router e favoritos salvos no navegador.
**React · TMDB API · React Router**
